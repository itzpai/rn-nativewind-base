# rn-nativewind

Base [Expo](https://docs.expo.dev/) (React Native) + [NativeWind](https://www.nativewind.dev/) starter.

## Get started

```bash
bun install
bun start
```

Scan the QR code with Expo Go, or press `a` (Android), `i` (iOS), or `w` (web).

Install packages with `bunx expo install <package>` so versions match the SDK.

## Layout

- Routes: `src/app/` (Expo Router)
- Styles: NativeWind `className` — config in `tailwind.config.js`, `global.css`, `babel.config.js`, and `metro.config.js`
